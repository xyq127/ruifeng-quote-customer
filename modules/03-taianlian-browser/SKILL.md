## Browser 操作模板

### 1. 导航到搜索页面

```python
browser_navigate(url="泰安联搜索页面URL")
```

### 2. 输入搜索条件

```python
# 输入内径
browser_type(ref="@eX", text="39")
# 输入外径
browser_type(ref="@eY", text="72")
# 输入高度
browser_type(ref="@eZ", text="00")
```

### 3. 提交搜索

```python
browser_click(ref="@eS")  # 点击搜索按钮
```

### 4. 获取结果

```python
browser_snapshot()  # 获取页面内容
# 或
browser_vision(question="请查看搜索结果表格中的所有产品信息，包括OE号、适配车型、参数")
```

### 5. 截图产品图片

```python
browser_vision(question="请截图当前页面的产品图片，我需要与后台产品图进行比对")
```

## 数据提取目标

每次查询需要提取以下信息：

| 字段 | 用途 |
|------|------|
| OE 号 | 与睿锋后台 OE 交叉验证 |
| 适配车型 | 验证 OE-车型映射是否正确 |
| 内径/外径/高度 | 与工厂编号解析结果一致性校验 |
| ABS 齿数 | 与工厂编号 ABS 参数比对 |
| 产品图片 | 与后台产品图肉眼比对 |
| 其他 OE/别名 | 补充关联编号 |

## 注意事项

1. **用户先登录**：Agent 不处理验证码，用户登录后通知 Agent 继续
2. **保持会话**：登录状态可能超时，操作前确认页面已登录
3. **反爬机制**：操作间隔保持 1-2 秒，避免频繁请求触发封禁
4. **图片比对由用户判断**：Agent 截图后发送给用户，用户肉眼判断是否一致
5. **URL 未知**：泰安联的具体网址需要用户提供或在首次使用时确认
