# 产品分类编号规律：轴承大类（num=10）

> 数据来源：后台 `/product/list` 按分类抽样统计（11 个子分类，各约 300 条，深沟轴承仅 16 条全量），
> 原始采样文件 `~/.claude/cache/category_samples.json`（不在本仓库内，仅供分析复用）。
>
> 本文档用于 quote-match 链路判断「输入编号属于一代/二代/三代、能否拆核心8位、属于哪个子分类」，
> 供 `quote_match.py` 在代码注释中引用，不需要程序动态读取本文件。

## 2. 核心8位编码：只存在于一代（DAC/DU 系）

核心8位 = 内径(2位) + 外径(2位) + 外径变型(2位) + 高度(2位)，规则与
`cross-catalog-dimension-matching.md` 一致。**只在分类03（双列球）和04（双列锥）的一代产品上存在**，
其他分类（含08轮毂单元的二代/三代）均不可拆8位。

### 2.1 分类03 双列球：DAC / WDAC

实测 248 条 DAC/WDAC 前缀编号中 232 条（93.5%，对应计划中「247/300 含8位」）能正确拆出8位数字。

| code 示例 | 核心8位 | 内径 | 外径 | 变型 | 高度 |
|---|---|---|---|---|---|
| WDAC45840045-2RZ(ABS88) | 45840045 | 45 | 84 | 00 | 45 |
| WDAC42820036-2RZ(ABS96) | 42820036 | 42 | 82 | 00 | 36 |
| DAC549500502RZ | 54950050 | 54 | 95 | 00 | 50 |

不可拆8位的反例（约 6.5%）：`W142011A`、`W145019E`、`133001E`、`128012D` 等——前缀非
`DAC`/`WDAC`、数字段不满8位，需走 OE/code 全字段精确匹配，不可走8位拆解。

### 2.2 分类04 双列锥：DU / GDU / PDU / RDU / KDU

实测 218 条 DU 系前缀编号中 217 条（99.5%，对应计划中「221/300」）能正确拆出8位数字。

| code 示例 | 核心8位 | 内径 | 外径 | 变型 | 高度 |
|---|---|---|---|---|---|
| DU559000552RZ | 55900055 | 55 | 90 | 00 | 55 |
| PDU49840048-2Z | 49840048 | 49 | 84 | 00 | 48 |
| KDU25550048RZ/ZK | 25550048 | 25 | 55 | 00 | 48 |

不可拆8位的反例：`510101A`（前缀非 DU 系，国际标准型号）。

## 3. 轮毂单元（分类08）：二代/三代 RAH/RAW 序列号 + T/K/C 系专用号

分类08下不存在核心8位编码，编号体系完全不同于03/04。

### 3.1 RAH / RAW + 序列号

格式为 `RAH` 或 `RAW` + 字母数字混合序列号（非尺寸编码），例：

| code 示例 | id | num | oe | bearingUnitStructure |
|---|---|---|---|---|
| RAH3C43 | 013427 | 1008019239 | 7082-S202R | 三代，卷边，螺栓、端盖、磁性圈 |
| RAH7C13 | 013396 | 1008019208 | 9900273620 | 二代半圆锥，卷边，螺栓、磁性圈、端盖 |
| RAW2A82 | 013356 | 1008019168 | W310300303 | 二代、螺栓、齿圈 |
| RAW3946 | 013282 | 1008019094 | A00010038 | （空，三代轮毂单元，name 字段标注） |

实测 RAH/RAW 前缀样本中：24 条 structure 含「二代」，60 条含「三代」，另有少量 structure
为空（需用 `name` 字段辅助判断，如「三代轮毂单元」）。**代数判断不能看 RAH/RAW 前缀本身**，
详见第8节。

### 3.2 T / K / C 系：疑似客户专用号

格式为单字母（`T`/`K`/`C`）+ 3位数字，无尺寸编码，structure 字段始终为空：

| code 示例 | id | num | oe | name |
|---|---|---|---|---|
| T799 | 014118 | 1008019244916921 | 23975659 | 前轮轴头 |
| T557 | 014107 | 1008019244916811 | 6665-L000-003 | 后轮轴头 |
| K048 | 014106 | 100801924491681 | 43502-12140 | 前轮轴壳 |
| K047 | 014074 | 100801924491651 | 43502-0D080 | 前轮轴壳 |

T/K/C 系不可拆8位，且 `num` 字段格式异常（见第7节例外）。

## 4. 单列锥轴承（分类01）：国际标准锥轴承型号系

不存在中国式编号，code 即国际标准型号（Timken 系为主），常见两种形态：

| 形态 | 示例 | 占比（实测300条） |
|---|---|---|
| 主号/配号（斜杠分隔，无 /P 后缀） | `LM11749/10`、`HM88648/10`、`WHM88648/HM88610` | 105/300 |
| 主号/配号 + 精度后缀 `/P5` `/P6` | `JP12049A/10`（计划示例）、`M88048/10/P6`、`LM11749/10/P6`、`KLM29749/11/P6X` | 60/300 |

`code` 与 `oe` 通常完全一致（覆盖率 300/300）。匹配时应整串比对，不可拆分数字段。

## 5. 其他序列号系对照表

均为 `RA?` 或 `JFK` 前缀 + 数字序列号，无尺寸编码，匹配时整串比对。

| 前缀 | 子分类 | 含义 | 实测占比 | 示例 |
|---|---|---|---|---|
| RAT | 07 张紧轮 | 张紧轮 | 297/300 | RAT2845、RAT2802 |
| RAC | 05 机械分离轴承 | 机械分离轴承 | 251/300 | RAC2512、RAC2509 |
| RAY | 06 液压分离轴承 | 液压分离轴承 | 69/114 | RAY3083、RAY3079 |
| RAZK / RAZKM | 10 一代圆锥轴承修理包 | 一代圆锥修理包 | 249/300 | RAZK7616、RAZKM047 |
| JFK / JFKM | 11 一代双列球轴承修理包 | 一代双列球修理包 | 300/300 | JFK0575B、JFKM192 |

## 7. num 结构：大类(10) + 子分类(2位) + 产品id(6位)

标准格式：`num = "10" + 子分类编号(2位) + id(6位，左侧补零)`，例如 `1011005108`
= 大类10 + 子分类11（一代双列球修理包）+ id `005108`。**num 前4位即可判断子分类**
（`1001`=单列锥、`1003`=双列球、`1004`=双列锥、`1005`=机械分离、`1006`=液压分离、
`1007`=张紧轮、`1008`=轮毂单元、`1009`=轮毂单元修理包、`1010`=一代圆锥修理包、
`1011`=一代双列球修理包；`1002`=深沟轴承）。

实测各分类 `num` 符合该10位标准格式的比例：

| 分类 | 符合标准格式 |
|---|---|
| 01/02/04/05/06/07/09/10/11 | 300/300（或16/16、114/114，全部符合） |
| 03 双列球轴承 | 273/300 |
| 08 轮毂单元 | 160/300 |

### 7.1 例外：08 轮毂单元中 T/K/C 系 num 异常（140/300）

T/K/C 系产品（见3.2节）的 `num` 字段长度为14-17位（如 `1008019244916921`），
**不是** `10`+`08`+6位id 的标准结构，前缀仍以 `1008` 开头但不能简单截取后6位当 id。
判断这类产品仍属于08分类应优先依据 `code` 前缀（`T`/`K`/`C` + 数字）而非 num 长度。

### 7.2 例外：03 双列球轴承中存在 27 条 num 落在 08 分类号段

这27条 `code` 为 `W14xxxx`/`WDAC...` 系（如 `W142011A`、`WDAC42820040-2RZA`），
`num` 形如 `1008019244531`（13位，`1008`开头），与所属分类03（标准应为 `1003...`）不一致。
这是后台历史数据的已知错位，**分类归属以接口返回的实际 category 为准，不可仅凭 num 前4位反推**。

## 8. RAH/RAW 代数判断：看 bearingUnitStructure，不看前缀

RAH 和 RAW 前缀**不区分二代/三代**，代数信息记录在 `bearingUnitStructure`
（采样字段名 `structure`）的文本内容中：

| structure 内容包含 | 代数 |
|---|---|
| 「二代」（如「二代半圆锥，卷边，螺栓、磁性圈、端盖」「二代、螺栓、齿圈」） | 二代 |
| 「三代」（如「三代，卷边，螺栓、端盖、磁性圈」） | 三代 |
| 「一代」（如「一代法兰盘、带花键、螺栓」，code 形如 RAH1C04） | 一代（轮毂单元一代款，仍无8位编码） |
| 空字符串 | 无法从此字段判代数，需结合 `name` 字段（如「三代轮毂单元」）或人工确认 |

T/K/C 系（3.2节）的 `bearingUnitStructure` 始终为空，且无法归类到任何一代/二代/三代，
应视为「专用号，跳过代数判断，直接按 code/oe 整串匹配」。
