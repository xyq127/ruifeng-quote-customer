# 17vin Web 端配件搜索验证

## 概述

17vin 网站提供配件号码搜索功能，比浏览器 EPC 导航快 10 倍（30秒 vs 5分钟每 OE）。适合**已知候选 OE 后快速验证**。

## 搜索 URL

```
https://www.17vin.com/partsearch/{OE号}.html
```

- OE 号中的横杠会被自动标准化（如 `11955-JA00A` → `11955JA00A`）
- 部分汽车品牌的 OE 在此搜索无收录（大众/奥迪/宝马/奔驰/福特返回"无结果"）
- 日系/韩系/法系 OE 通常有收录

## 详情页 URL

点击"适用车型和替换号"后跳转到：

```
https://www.17vin.com/modellist/{OE号}/{group_id}.html?p=...
```

详情页包含：
- **配件信息：** 品牌、配件号码、配件名称（中英文）、4S店价格
- **配件分解图：** EPC 图号、标准名称、类目信息（发动机/年份区间）
- **原厂替换号列表：** 同品牌不同序号 OE
- **普通替换号列表：** Gates/DAYCO/INA/SKF 等副厂编号
- **适用车型列表：** 具体年款+发动机代码（部分 OE 的此项为空）

## 通过配件名称验证物理形态

关键判断：

| 17vin 配件名称 | 物理形态 | 置信度 |
|---------------|---------|--------|
| "发动机皮带涨紧器;张紧轮总成" | 张紧器总成 | ✅ |
| "自动张紧器" | 张紧器总成 | ✅ |
| "多楔带张紧器总成" | 张紧器总成 | ✅ |
| "BELT, ALTERNATOR (BANDO)" | 发电机皮带（不是张紧器！） | ❌ 知识库错误 |
| "Tensioner Pulley, v-ribbed belt" | 三角楔形皮带张紧轮 | ✅ |

## 适用车型列表验证

17vin 适用车型列表显示的发动机代码用于**精准确认适配性**：

例：`252812G000` 适配车型列表显示发动机为 G4KD/G4KE/G4KJ/G4KH（Theta-II 系列），
**不适用** G6BA (途胜2.7 V6)、G6EA (新胜达2.7)、G6DA (维拉克斯3.8)。

## 在本项目中的使用时机

1. **知识库 OE 候选 → Web 搜索验证：** 确认配件类型（张紧器 vs 皮带 vs 惰轮）
2. **车型列表交叉校验：** 确认 OE 适配的发动机代码与用户输入的发动机是否一致
3. **发现知识库错误后修正：** 如 `31110-RAA-A01` 实际是发电机皮带非张紧器
