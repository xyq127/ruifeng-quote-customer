# 跨目录尺寸匹配：核心8位编号匹配法

## 场景

当两份产品清单（如退货汇总表、库存表）需要用产品编号互相匹配时，DAC/DU 产品常因后缀差异无法精确匹配。

## 匹配策略（优先级递减）

### 策略1：精确匹配
存货名称与参照表编号完全一致（含组合编号拆分）。

### 策略2：核心8位精确匹配
提取8位核心编号（内径+外径+变型+高度），忽略所有后缀。
> 用户明确指示：只要8位核心编号相同，材料、封装、密封（2RZ/RS/RZ/Z）、ABS 后缀不影响匹配。

### 策略3：近似匹配（同内径+外径，高度/变型接近）
当核心8位不完全匹配，但**内径+外径相同**，且满足以下条件时可用同样规格包装：
- **高度差 ≤ 2mm**
- **变型差 ≤ 8**（合理范围内）

**这是用户的明确指令**："变型/高度不同差距不大的可以用同样规格的包装"。

| 示例 | 内径 | 外径 | 变型 | 高度 | 匹配结果 |
|------|------|------|------|------|---------|
| DU55900055-RZ/RS → DU55900054-2RZ/ABS | 55 | 90 | 00→00 | 55→54 (差1) | ✅ 匹配 |
| DAC40720836-RZ/RS(ABS88) → DAC40720036-RZ/RS | 40 | 72 | 08→00 (差8) | 36→36 (差0) | ✅ 匹配 |

**优先级**：精确匹配 > 核心8位匹配 > 近似匹配，越接近的优先。

### 策略4：前缀匹配（非DAC/DU项）
如 RAH2014A → RAH2014（参照表有基础款）。

## 编号解析

工厂编号格式：`{前缀}{内径2位}{外径2位}{外径变型2位}{高度2位}{后缀}`

| 示例 | 核心8位 | 内径 | 外径 | 变型 | 高度 |
|------|---------|------|------|------|------|
| DAC39720037-2RZ(ABS88) | 39720037 | 39 | 72 | 00 | 37 |
| DU54920050-2RZ/ABS | 54920050 | 54 | 92 | 00 | 50 |
| DAC42840040-2RZ（ABS96）（停用） | 42840040 | 42 | 84 | 00 | 40 |
| DAC35680037-2RZ（ABS96） | 35680037 | 35 | 68 | 00 | 37 |
| DAC40720836-RZ/RS(ABS88) | 40720836 | 40 | 72 | 08 | 36 |

**后缀全忽略**：`-2RZ`、`(ABS96)`、`-RZ/Z`、`（停用）`、全角括号等一律不影响匹配。

## 不可匹配的情况

| 产品 | 原因 |
|------|------|
| LM300849/11, LM603049/11 | 锥轴承非DAC/DU格式，无可拆解尺寸 |
| RAH2526, RAH3277 等轮毂单元 | 无法拆解尺寸，需从后台获取参数 |
| DAC45830044 | 外径83mm，参照表最近是82/84，OD不同不可匹配 |
| DAC38.1720037 | 含小数点（内径38.1mm非38），参照表无38.1规格 |

## 参考脚本

```python
import re

def extract_core_8(name):
    """提取DAC/DU的8位核心编号（内径+外径+变型+高度）"""
    s = str(name).strip()
    if not s:
        return None
    # letters + 8 digits + anything
    m = re.match(r'^([A-Za-z]*)(\d{8})(.*)$', s)
    if m:
        return m.group(2)
    # pure numeric
    m = re.match(r'^(\d+)$', s)
    if m:
        return m.group(1)
    return None

def parse_dimensions(name):
    """解析为 (id, od, var, ht) 元组"""
    core = extract_core_8(name)
    if core and len(core) == 8:
        return int(core[0:2]), int(core[2:4]), int(core[4:6]), int(core[6:8])
    return None

def is_approx_match(t_dims, r_dims, ht_max_diff=2, var_max_diff=8):
    """判断是否可以近似匹配（同内径外径，高度/变型接近）"""
    if t_dims is None or r_dims is None:
        return False
    t_id, t_od, t_var, t_ht = t_dims
    r_id, r_od, r_var, r_ht = r_dims
    return (t_id == r_id and t_od == r_od
            and abs(t_ht - r_ht) <= ht_max_diff
            and abs(t_var - r_var) <= var_max_diff)
```
