# 补货计划/入库数据质量抽检指南

## 何时使用

用户提供补货计划 Excel 文件时，在正式入库或进入清洗流程前，先做数据质量抽检，发现结构性问题。

## Excel 列语义（2026-05-14 修正）

| 列字母 | 表头标签 | 实际含义 | 示例 |
|--------|---------|---------|------|
| B | 工厂编码 | 系统 code（唯一标识） | RAH3655 |
| C | 工厂型号 | **OE（主编号/原厂零件号）** | 43202-4CL0A |
| G | OE | **关联编号（交叉引用列表）** | 43202-4CL0A, 512534... |
| I | 雷迪克编号 | 冗余（通常 = 工厂编码） | RAH3655 |

**注意**：C列才是真正的OE号，G列是关联编号。G列为空或为0 = 缺少关联编号。

## 抽检流程

### 1. 读取文件结构

```python
import openpyxl, random
wb = openpyxl.load_workbook('文件路径.xlsx', data_only=True)
ws = wb['Sheet1']  # 或遍历 wb.sheetnames
# 表头在第1行，数据从第2行开始
```

### 2. 全表维度质量检查

| 检查项 | 阈值 | 说明 |
|--------|------|------|
| 关联编号缺失（G列） | 应 = 0 | G列为空或为0表示无关联OE，需补充 |
| 工厂编码重复 | 应 = 0 | 除非不同变型需要多行，否则是重复数据 |
| DAC 编码格式异常 | 应 = 0 | 标准格式：`DAC{ID2}{OD2}{VAR2}{H2}-{后缀}` |
| 序号缺失率 | 应 < 20% | 缺失不影响数据但影响可读性 |

### 3. 产品类型分类

**根据B列工厂编码前缀判定：**

| 前缀 | 类型 | 参数可拆解 | 泰安联搜索方式 |
|------|------|----------|-------------|
| DAC / DU / GDU | 一代轴承 | ✅ 内径×外径×变型×高度 | 用8位纯数字（去掉前缀后缀） |
| RAH / RAW | 二代/三代轮毂单元 | ❌ 无法拆解 | 用OE号（C列工厂型号）搜索 |

### 4. 随机抽样详细检查

```python
rows = []  # 收集所有数据行
random.seed(42)  # 固定种子可复现
sampled = random.sample(rows, min(8, len(rows)))
```

对每个抽样产品检查：
- 工厂编码（B列）= 系统code
- OE号（C列工厂型号）是否非空且非0
- 关联编号（G列）是否完整
- 名称与车型是否合理对应
- 销售等级（A/B/C/D）是否填写

### 5. 泰安联 CDP 交叉验证（抽检核心步骤）

**一代轴承（DAC/DU/GDU）**：
```
泰安联搜索：8位纯数字（去掉前缀后缀）
例：DAC42820036-2RZ → 搜索 42820036
验证：内径/外径/高度参数、关联OE号、适配车型
```

**轮毂单元（RAH/RAW）**：
```
泰安联搜索：OE号（C列工厂型号）
例：RAH3451, OE=MR594979 → 搜索 MR594979
验证：安装位置、关联OE号、车型匹配
```

搜索URL：`https://www.tecalliance.cn/cn/search/1?q={关键词}&numbersearchinput=1&searchtype=0&status=1`

通过 `browser_navigate` 直接导航（点击按钮不触发搜索）。

**验证要点**：
- OE存在性：泰安联是否返回结果
- 安装位置：前轴/后轴/左/右是否与产品描述一致
- 参数匹配：一代轴承的内径/外径/高度
- 车型匹配：泰安联返回的车型与Excel中的车型是否对应
- 关联编号：泰安联返回的OE号与Excel关联编号的交叉验证

### 6. 特殊格式识别

**DAC 编码解析**：`DAC{内径2}{外径2}{变型2}{高度2}-{后缀}`
- 标准：`DAC42820036-2RZ` → 内径42 / 外径82 / 变型00 / 高度36
- 斜杠变体：`DAC39/41750037-2RS`（内径双值 39/41mm）
- 斜杠变体：`DAC39740036/34-2RZ`（高度双值 36/34mm）

**RAH 编码**（轮毂单元）：
- 格式：`RAHxxxxx`（如 RAH3655），无法拆解参数
- 雷迪克编号 = 工厂编码

**RAW 编码**：
- 格式：`RAWxxxx`，较少见，需确认编号规则

**DU/GDU 编码**：
- 与 DAC 同类一代轴承，解析规则相同

## 常见数据质量问题

1. **关联编号（G列）为空**：最常见，一代轴承常缺车辆原厂OE号
2. **重复行**：需确认是否为不同变型或纯重复
3. **DAC 编码解析失败**：斜杠格式 `/` 需要特殊处理
4. **序号缺失**：补货计划通常不填序号，非关键

## 输出格式

抽检报告包含：
- 总体概况（产品数、分类分布）
- 抽样产品逐一检查表（含泰安联验证结果）
- 全表维度质量问题汇总
- 修复建议优先级
