# 宜配网 (yiparts.com) 查询指南

## 概述

宜配网是中国汽配门户网站（用户 c481371 已登录），可作为 OE 号验证的补充数据源。

## 使用方法

### 号码搜索（唯一有效方式）

URL 格式：`https://www.yiparts.com/search?type=number&keyword=产品编号前缀`

**关键词提取规则**：去掉前缀（DAC/DU/GDU）和后缀（2RZ/ABS96/RS 等），只保留中间数字部分：

| 工厂编号 | 搜索关键词 |
|---------|----------|
| DAC407500402RZ | DAC40750040 |
| DU407300552RZ/ABS96 | DU40730055 |
| DAC428400402RZ(ABS96) | DAC42840040 |
| DAC40.37802382RZ(ABS96) | DAC4037802382 |
| GDU356800482RZ | GDU35680048 |

> ⚠️ 注意：保留前缀字母（DAC/DU/GDU），不要只搜索纯数字。

### 批量查询

使用 `delegate_task` 分3个子agent并行，每个子agent用 `browser_navigate` 直接访问搜索URL。

> ⚠️ 宜配网有 JS 重定向机制，直接 `browser_navigate` 可能被重定向。如遇重定向，使用 `browser_cdp` 调用 `Page.navigate` 绕过。

## 数据特征

### 找到的数据格式

页面会显示第三方 Autosearcher 数据，结构如下：
- **标题**：`EBI 轮毂轴承(Axle beam) EB{型号}`
- **OEMparts**：OE 号（如 DAC40750040）
- **安装位置**：Axle beam（车桥）
- **来源**：autosearcher.ru

### 未找到的情况

页面显示："抱歉，未找到当前条件下的相关宜配数据！"

## 局限性（重要）

1. **无车型适配信息**：宜配网只返回 OE 号和安装位置，不提供具体适配车型。不能通过车型反向查 OE。
2. **覆盖率约 50%**：2026-06 测试 13 个产品，仅 6 个有数据（均为 EBI 品牌轮毂轴承）。
3. **第三方数据**：数据来源是 Autosearcher，不是宜配网自有数据库，权威性一般。
4. **品牌偏好**：找到的均为 EBI 品牌，其他品牌数据较少。

## 在清洗流程中的定位

| 数据源 | OE 交叉引用 | 车型适配 | 中国品牌覆盖 |
|-------|-----------|---------|------------|
| 泰安联 TecDoc | ✅ 强 | ✅ 有 | ❌ 基本无 |
| 17vin EPC | ✅ 强 | ✅ 最强 | ⚠️ API 部分支持 |
| **宜配网** | ✅ 中等 | ❌ **无** | ⚠️ 部分有 |
| **电商平台(淘宝/京东/1688)** | ⚠️ 需人工提取 | ❌ 无 | ✅ 有 |

**使用场景**：作为 OE 号确认的补充验证渠道，尤其是当泰安联和 17vin 都没有数据时，可以多一个来源佐证。但不适合用来查找车型适配信息。
